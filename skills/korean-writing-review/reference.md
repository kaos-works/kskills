# 문맥에 따른 판단

표현을 기계적으로 치환하지 않는다.수정의 이유는 독자의 이해를 막는 구체적인 문제여야 한다.

| 상황 | 수정 방향 | 보존할 반례 |
|---|---|---|
| 핵심 행동이 배경에 묻힘 | 안내·요청을 먼저 드러내기 | 회고의 깨달음·서사 순서 |
| 주체·대상 생략 | 문맥에 있는 정보 복원 | 없는 주체를 추정하지 않기 |
| 긴 논리 사슬 | 주제·행위별로 분할 | 두 필수 조건을 독립 조건으로 바꾸지 않기 |
| 추상적인 성과 | 원문에 있는 작업·결과로 표현 | 근거 없으면 측정값을 발명하지 않기 |
| 반복 | 기능 없는 재진술 줄이기 | 범위·안전·절차 확인에 필요한 반복 |
| 경로 표현 | 불필요한 우회 표현 줄이기 | 담당자·통역사 경유가 필수인 절차 |
| 완곡 표현 | 중복 완곡만 정리 | 예상·미측정·표본 한계 보존 |
| 기술 용어 | 독자에게 필요한 풀이 추가 | 코드·API 식별자와 정착 용어 |
| 문단 연결 | 같은 주제끼리 묶고 연결 관계 확인 | 시간 순서를 인과로 단정하지 않기 |
| 부분 발췌 | 전체 원문과 대조 | 요약표에서 빠졌다는 이유로 본문 정보 삭제 금지 |

## 자체 작성한 예시

- ‘담당자를 통해 제출해야 합니다’에서 담당자 경유가 의무라면 유지한다.
- ‘금요일까지 답변할 수 있는지 확인하겠습니다’를 ‘금요일까지 답변하겠습니다’로 바꾸지 않는다.
- ‘배포 후 오류가 늘었고 원인은 미확인’에서 배포를 원인으로 단정하지 않는다.
- ‘계약 종료와 정산 완료 시에만 반환’은 두 조건이 모두 필요하다.

## 근거와 한계

연구자의 종합 기준이며 다음 자료를 통째로 이식한 것이 아니다. 한국어 공개 교정 자료와 로컬 korean-doc-general의 구조·의미 보존 원칙을 참고했다. 위 예시는 자체 작성했다. 이 스킬은 다른 스킬의 실행을 요구하지 않는다.

- [국립국어원 문화재 안내문 교정 자료](https://korean.go.kr/common/download.do?c_file_name=0e172156-17bd-4b8d-b4e2-6e04141c2b43_0.pdf&file_path=etcData&o_file_name=한눈에%20알아보는%20문화재%20안내문%20바로%20쓰기_보급용.pdf), PDF 14·55쪽.
- [김광해, 법원 판결문의 문장(10)](https://www.korean.go.kr/nkview/nknews/200002/19_3.htm): 문장 분할과 논리 연결. 법적 의미의 동등성을 검증한 자료로 사용하지 않는다.
- [GitHub 스타일 가이드](https://docs.github.com/ko/contributing/style-guide-and-content-model/style-guide): 독자·맥락에 따른 판단.

규칙의 효용은 장르별 실행으로 검증해야 한다. 출처가 있다는 사실만으로 이 스킬의 효과가 입증되는 것은 아니다.
